# 03 - Build Your Agent

The centerpiece of the workshop. You'll set up a real personal AI agent on Telegram — the same platform the instructor runs 24/7.

## Step-by-step guide

Follow the **[OpenClaw setup guide](track_a/track-a-openclaw.md)** — it walks you through everything:

1. Install OpenClaw
2. Create a Telegram bot
3. Run onboarding
4. Test it
5. Create workspace files (personality + safety rules)
6. Add proactive scheduling

Templates for workspace files are in [templates/](track_a/templates/).
