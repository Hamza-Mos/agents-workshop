## Agents you can use right now for school, co-op, and work

The same primitives you just learned (tool calling, agent loops, memory) power real tools you can start using today:

### Research & studying
- **[Elicit](https://elicit.com)** — search and summarize 125M+ papers. "Find papers on [topic] and extract the key findings."
- **[Semantic Scholar](https://www.semanticscholar.org)** — free AI-powered paper search from AI2.
- **[Consensus](https://consensus.app)** — ask a research question, see which studies agree/disagree.
- **[Connected Papers](https://www.connectedpapers.com)** — visual citation graphs to find related work.

### Writing & reviewing
- **[Paperpal](https://paperpal.com)** — writing support, grammar, plagiarism checks.
- **[Scite](https://scite.ai)** — see how a paper has been cited: supported, contradicted, or just mentioned.

### Coding
- **Claude Code, Cursor, GitHub Copilot** — coding agents with tool calling under the hood. Same pattern you built today.
- **[Agent Skills](https://agentskills.io)** — open standard for giving agents new capabilities. Works across 30+ products.

### What's coming
- Karpathy's [autoresearch](https://github.com/karpathy/autoresearch) — agents running 100 ML experiments overnight on a single GPU
- [PraxLab](https://github.com/Hamza-Mos/praxlab) — autonomous experiment harness. Humans set strategy, agents handle tactics.
- DeepMind's Aletheia solved 4 unsolved math problems autonomously — but got 68.5% wrong on the broader test. Part 04 applies here too.
